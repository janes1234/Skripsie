\chapter{Hyperparameter Search Trials}{}
\makeatletter\@mkboth{}{Appendix}\makeatother
\label{appen:hyperparam_trials}

Section~\ref{sec:exp_hyperparams} describes the Optuna hyperparameter search used for six of the project's architectures. This appendix lists every trial that search ran, so the results in that section can be checked in full without cluttering the main text with 120 rows of trial data. For each architecture, the winning trial (the one whose values were carried forward to training) is shaded.
