\chapter{Hyperparameter Search Trials}{}
\makeatletter\@mkboth{}{Appendix}\makeatother
\label{appen:hyperparam_trials}

Section~\ref{sec:exp_hyperparams} describes the Optuna hyperparameter search used for six of the project's architectures, which was run separately for the clarifiers and for the aerobic zones. This appendix lists every trial of these twelve searches, so the results in that section can be checked in full without cluttering the main text with 240 rows of trial data. For each search, the winning trial (the one whose values were carried forward to training) is shaded.
